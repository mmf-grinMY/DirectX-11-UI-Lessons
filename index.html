Урок 1. Основы HLSL и памяти GPU

Прежде чем писать шейдеры, пойми, где живут данные и как GPU их читает. Иерархия памяти и правила доступа — важнее синтаксиса.

1.1. Иерархия памяти

УровеньРазмерСкоростьДоступ

L2 Cache2–100 MB~5–10× VRAMОбщая для всех SM

Главный ресурс — пропускная способность. Латентность VRAM ~400–800 тактов. GPU скрывает её тысячами потоков параллельно, но только если обращения «дружные».

1.2. Модель исполнения и коалесинг

  • Потоки группируются в warp'ы (NVIDIA, 32 потока) / wavefronts (AMD, 64).
  • Все потоки warp'а выполняют одну инструкцию одновременно (SIMD).
  • Если 32 потока читают подряд идущие адреса — одна транзакция памяти, 100% эффективности.
  • Если вразнобой — до 32 транзакций, ~3% эффективности. Разница в 32 раза.
Правило коалесинга: любые данные для warp'а должны лежать подряд. Особенно критично для StructuredBuffer, вершинных буферов, текстур с Point-сэмплером.

1.4. cbuffer — выравнивание по 16 байт

Каждая переменная в cbuffer начинается с offset, кратного 16. Если float3 идёт после float4x4, он займёт 16 байт (не 12), потому что следующий float должен быть выровнен.

cbuffer PerFrame : register(b0)
{
    float4x4 viewProj;      // offset 0, 64 байта
    float3   cameraPos;     // offset 64, займёт 16 (12 + 4 паддинг)
    float    time;          // offset 76 — пакуется в те же 16
    float4   tint;          // offset 80, 16 байт
};
Самая частая ошибка новичка: «матрица приходит кривой». Причина — забыл про 16-байтовое выравнивание, C++-struct не совпал с cbuffer-layout. В debug пиши static_assert(sizeof(PerFrame) % 16 == 0).

1.6. Функции и параметры

float3 Lambert(float3 N, float3 L, float3 albedo)
{
    float ndl = saturate(dot(N, L));
    return albedo * ndl;
}

void SchlickFresnel(float3 F0, float cosTheta, out float3 F)
{
    F = F0 + (1.0 - F0) * pow(1.0 - cosTheta, 5.0);
}

1.11. mul — главный источник боли

DirectXMath хранит матрицы row-major. HLSL по умолчанию читает как column-major. Если передать как есть — получишь мусор. Стандартный паттерн:

// C++ — транспонировать при отправке
XMStoreFloat4x4(&data->viewProj, XMMatrixTranspose(viewProj));

// HLSL — вектор × матрица (строка)
o.position = mul(float4(input.pos, 1.0), viewProj);
90% «чёрных экранов» и «всё сломано» — здесь. Запомни наизусть: transpose на CPU + mul(v, M) в HLSL. Альтернатива — объявить в HLSL row_major float4x4 и передавать без транспонирования, но это менее универсально.

1.12. Итог урока

  • Память GPU — иерархия; главное — коалесинг.
  • cbuffer — выровнен по 16 байт, иначе «мусор в матрицах».
  • Регистры b/t/s/u — привязка ресурсов.
  • Семантика — контракт между стадиями.
  • mul + транспонирование — главная ловушка.

Урок 2. Инициализация D3D11 через ComPtr/WRL

DirectX 11 — чистый COM. ComPtr — умный указатель, аналог unique_ptr с COM-семантикой. Без него — гарантированные утечки.

2.1. ComPtr — таблица

МетодЧто делает
p.Get()Сырой указатель (без AddRef) для передачи в функции
p.GetAddressOf()T** для out-параметров. Вызывает Release старого
p.ReleaseAndGetAddressOf()T**, не вызывает Release

Никогда не смешивай сырые указатели и ComPtr на одном объекте. Либо весь код на ComPtr, либо вручную AddRef/Release. Смешение — источник утечек и double-free.

2.5. Создание device и swap chain (bitblt)

main.cpp · часть 3 · CreateDeviceAndSwapChain
bool D3DApp::CreateDeviceAndSwapChain(HWND hwnd, UINT w, UINT h) {
    UINT flags = D3D11_CREATE_DEVICE_BGRA_SUPPORT;
#ifdef _DEBUG
    flags |= D3D11_CREATE_DEVICE_DEBUG;
#endif
    const D3D_FEATURE_LEVEL levels[] = {
        D3D_FEATURE_LEVEL_11_1,
        D3D_FEATURE_LEVEL_11_0,
    };
    D3D_FEATURE_LEVEL obtained{};

    HRESULT hr = D3D11CreateDevice(
        nullptr, D3D_DRIVER_TYPE_HARDWARE, nullptr, flags,
        levels, _countof(levels), D3D11_SDK_VERSION,
        &m_device, &obtained, &m_context);
    // 11_1 может отсутствовать на старом железе
    if (hr == E_INVALIDARG) {
        hr = D3D11CreateDevice(
            nullptr, D3D_DRIVER_TYPE_HARDWARE, nullptr, flags,
            &levels[1], _countof(levels) - 1, D3D11_SDK_VERSION,
            &m_device, &obtained, &m_context);
    }
    if (FAILED(hr)) Fatal("D3D11CreateDevice", hr);

    // DXGI Factory через Adapter
    ComPtr<IDXGIDevice>  dxgiDevice;
    CHECK(m_device.As(&dxgiDevice));
    ComPtr<IDXGIAdapter> adapter;
    CHECK(dxgiDevice->GetAdapter(&adapter));
    ComPtr<IDXGIFactory> factory;                        // DXGI 1.0!
    CHECK(adapter->GetParent(IID_PPV_ARGS(&factory)));

    // Bitblt-модель swap chain
    DXGI_SWAP_CHAIN_DESC desc = {};
    desc.BufferDesc.Width                   = w;
    desc.BufferDesc.Height                  = h;
    desc.BufferDesc.Format                  = DXGI_FORMAT_B8G8R8A8_UNORM;
    desc.BufferDesc.RefreshRate.Numerator   = 0;     // 0 = don't care
    desc.BufferDesc.RefreshRate.Denominator = 1;
    desc.SampleDesc.Count                   = 1;
    desc.BufferUsage                        = DXGI_USAGE_RENDER_TARGET_OUTPUT;
    desc.BufferCount                        = 2;
    desc.OutputWindow                       = hwnd;
    desc.Windowed                           = TRUE;
    desc.SwapEffect                         = DXGI_SWAP_EFFECT_DISCARD;

    CHECK(factory->CreateSwapChain(m_device.Get(), &desc, &m_swapChain));
    CHECK(factory->MakeWindowAssociation(hwnd, DXGI_MWA_NO_ALT_ENTER));
    return true;
}

bool D3DApp::CreateBackBufferRTV() {
    ComPtr<ID3D11Texture2D> backBuffer;
    CHECK(m_swapChain->GetBuffer(0, IID_PPV_ARGS(&backBuffer)));
    CHECK(m_device->CreateRenderTargetView(backBuffer.Get(), nullptr, &m_rtv));
    return true;
}
DXGI 1.0 vs 1.2. dxgi.h — Win7+, bitblt. dxgi1_2.h — Win8+, flip-model, ниже задержка. Для 2D-обучения разница несущественна. Bitblt допускает BufferCount = 1 (типично), flip — минимум 2.

2.7. Render loop и Present

void D3DApp::Render() {
    const float clear[4] = { 0.10f, 0.10f, 0.15f, 1.0f };
    m_context->ClearRenderTargetView(m_rtv.Get(), clear);

    ID3D11RenderTargetView* rtvs[] = { m_rtv.Get() };
    m_context->OMSetRenderTargets(1, rtvs, nullptr);

    D3D11_VIEWPORT vp{ 0, 0, (float)m_width, (float)m_height, 0, 1 };
    m_context->RSSetViewports(1, &vp);
    m_context->RSSetState(m_raster.Get());

    // draw call здесь (в уроке 3)

    m_swapChain->Present(1, 0);   // 1 = ждать VSync
}

2.8. Resize — критично

void D3DApp::Resize(UINT w, UINT h) {
    if (w == 0 || h == 0) return;
    if (w == m_width && h == m_height) return;

    m_width = w; m_height = h;

    // ОБЯЗАТЕЛЬНО: отпустить view до ResizeBuffers
    m_rtv.Reset();

    CHECK(m_swapChain->ResizeBuffers(
        0,                     // 0 = сохранить BufferCount
        w, h,
        DXGI_FORMAT_UNKNOWN,   // сохранить формат
        0));

    CreateBackBufferRTV();
}
ResizeBuffers падает с DXGI_ERROR_INVALID_CALL, если на back-buffer остались живые ссылки (RTV, сохранённый Texture2D). Перед вызовом — m_rtv.Reset().

static D3DApp g_app;
static bool   g_running = true;
LRESULT CALLBACK WndProc(HWND hwnd, UINT msg, WPARAM wp, LPARAM lp) {
    switch (msg) {
    case WM_DESTROY:
        g_running = false; PostQuitMessage(0); return 0;
    case WM_SIZE:

        return 0;
    case WM_KEYDOWN:

        return 0;
    }
    return DefWindowProcW(hwnd, msg, wp, lp);
}

    WNDCLASSEXW wc{};

    wc.hbrBackground = (HBRUSH)GetStockObject(BLACK_BRUSH);

    RegisterClassExW(&wc);

    const UINT W = 1280, H = 720;
    RECT r{ 0, 0, (LONG)W, (LONG)H };
    AdjustWindowRectEx(&r, WS_OVERLAPPEDWINDOW, FALSE, 0);

    HWND hwnd = CreateWindowExW(0, wc.lpszClassName, L"D3D11 2D App",
        WS_OVERLAPPEDWINDOW, CW_USEDEFAULT, CW_USEDEFAULT,
        r.right - r.left, r.bottom - r.top,
        nullptr, nullptr, hInst, nullptr);
    if (!hwnd) Fatal("CreateWindowExW");

    if (!g_app.Init(hwnd, W, H)) return 1;
    ShowWindow(hwnd, SW_SHOW);

    while (g_running) {
        while (PeekMessageW(&msg, nullptr, 0, 0, PM_REMOVE)) {
            if (msg.message == WM_QUIT) { g_running = false; break; }
            TranslateMessage(&msg); DispatchMessageW(&msg);
        }
        if (g_running) g_app.Render();
    }
    g_app.Destroy();
    return 0;
}

3.7. Draw call — полный пайплайн кадра

void D3DApp::Render() {
    m_context->ClearRenderTargetView(m_rtv.Get(), clear);

    ID3D11RenderTargetView* rtvs[] = { m_rtv.Get() };
    m_context->OMSetRenderTargets(1, rtvs, nullptr);

    D3D11_VIEWPORT vp{ 0, 0, (float)m_width, (float)m_height, 0, 1 };
    m_context->RSSetViewports(1, &vp);
    m_context->RSSetState(m_raster.Get());

    // Обновление cbuffer
    XMMATRIX wvp = XMMatrixOrthographicOffCenterLH(0, (float)m_width,
        (float)m_height, 0, 0, 1);
    D3D11_MAPPED_SUBRESOURCE m;
    if (SUCCEEDED(m_context->Map(m_cbuffer.Get(), 0, D3D11_MAP_WRITE_DISCARD, 0, &m))) {
        XMStoreFloat4x4(&static_cast<Constants*>(m.pData)->wvp,
                        XMMatrixTranspose(wvp));
        m_context->Unmap(m_cbuffer.Get(), 0);
    }
    // IA
    m_context->IASetInputLayout(m_inputLayout.Get());
    UINT stride = sizeof(Vertex), offset = 0;
    ID3D11Buffer* vbs[] = { m_vb.Get() };
    m_context->IASetVertexBuffers(0, 1, vbs, &stride, &offset);
    m_context->IASetIndexBuffer(m_ib.Get(), DXGI_FORMAT_R32_UINT, 0);
    m_context->IASetPrimitiveTopology(D3D11_PRIMITIVE_TOPOLOGY_TRIANGLELIST);

    // Шейдеры + cbuffer
    m_context->VSSetShader(m_vs.Get(), nullptr, 0);
    m_context->PSSetShader(m_ps.Get(), nullptr, 0);
    ID3D11Buffer* cbs[] = { m_cbuffer.Get() };
    m_context->VSSetConstantBuffers(0, 1, cbs);

    // Draw
    m_context->DrawIndexed(3, 0, 0);

    m_swapChain->Present(1, 0);
}

Что происходит внутри DrawIndexed(3, 0, 0):

  1. IA читает 3 индекса → выбирает 3 вершины из VB.
  2. Распаковывает по input layout → VS.
  3. VS выполняется 3 раза (по вершине).
  4. Rasterizer собирает треугольник → NDC → viewport → интерполяция.
  5. PS выполняется для каждого пикселя → RTV.
cbuffer — 3 правила: (1) ByteWidth % 16 == 0; (2) DYNAMIC + CPUAccess = WRITE; (3) только Map(WRITE_DISCARD). Другие флаги — не для cbuffer.

Формула перехода:

physical = logical * (dpi / 96) * renderScale

Три коэффициента, которые нельзя путать:

  1. Системный DPI — пользовательская настройка «Размер текста» в Windows. 96–480.
  2. DPI монитора — физическая плотность. У Retina огромный, но системный остаётся 96 + OS-масштабирование битмапом.
  3. Render scale — собственный множитель (например, 0.5 для half-res).

4.2. Subpixel — нормально

x = 100.3f — отлично, GPU растеризует с субпиксельной точностью, MSAA/AA сгладит. Округлять до целых — только для текста (crispness) и границ скролла.

Урок 5. Спрайты: WIC, premultiplied alpha

Урок 5. Спрайты: WIC, premultiplied alpha

Главная концепция D2D, которую новички постоянно путают. Ореолы вокруг спрайтов — это провал premultiplied.

5.1. Две модели цвета

Straight: (R, G, B, A) — RGB чистый, A отдельно.
Premultiplied: (R×A, G×A, B×A, A) — RGB заранее умножен.

Для A=255 — идентичны. Для полупрозрачных — разные.

5.2. Blend «over» и почему premultiplied

// Straight:
C_out = C_src * A_src + C_dst * (1 - A_src)   →   SrcBlend = SRC_ALPHA

// Premultiplied:
C_out = C_src_premult + C_dst * (1 - A_src)   →   SrcBlend = ONE

Главная причина premultiplied — bilinear-интерполяция. PNG с чёрным текстом на прозрачном фоне. Край: (0,0,0,0) — чёрный, alpha=0. Внутри: (0,0,0,255).

При уменьшении/увеличении bilinear интерполирует 4 соседних texel'а. Переход «внутри → край»:

StraightPremultiplied
Inside(0, 0, 0, 255)(0, 0, 0, 255)
Edge(0, 0, 0, 0)(0, 0, 0, 0)
Interpolated(0, 0, 0, 127) ✓(0, 0, 0, 127) ✓

Но если PNG хранит белый под прозрачностью (так делают многие редакторы):

StraightPremultiplied
Inside(0, 0, 0, 255)(0, 0, 0, 255)
Edge (белый под)(255, 255, 255, 0)(0, 0, 0, 0)
Interpolated(127, 127, 127, 127) ✗ серый ореол(0, 0, 0, 127) ✓

Вывод: premultiplied — единственный способ, при котором RGB прозрачных пикселей «не тянет» цвет в интерполяцию.

bool CreateTestAtlas(ID3D11Device* device, ID3D11ShaderResourceView** outSRV) {

    std::vector<uint32_t> px(size_t(S) * S, 0);

    auto set = [&](UINT x, UINT y, uint8_t r, uint8_t g, uint8_t b, uint8_t a) {
        uint32_t pr = (uint32_t(r) * a) / 255;
        uint32_t pg = (uint32_t(g) * a) / 255;
        uint32_t pb = (uint32_t(b) * a) / 255;
        px[size_t(y) * S + x] =
            (uint32_t(a) << 24) | (pr << 16) | (pg << 8) | pb;
    };

    for (UINT y = 0; y < S; ++y) {
        for (UINT x = 0; x < S; ++x) {
            int qx = x / 128, qy = y / 128;
            int lx = x % 128, ly = y % 128;
            if (qx == 0 && qy == 0) {
                float dx = lx - 63.5f, dy = ly - 63.5f;
                float d = sqrtf(dx*dx + dy*dy);
                float alpha = fminf(1.0f, 64.0f - d);
                if (alpha > 0) set(x, y, 230, 60, 60, uint8_t(alpha * 255));
            } else if (qx == 1 && qy == 0) {
                if (lx >= 16 && lx < 112 && ly >= 16 && ly < 112)
                    set(x, y, 60, 230, 60, 255);
            } else if (qx == 0 && qy == 1) {
                float d = fabsf(lx - 63.5f) + fabsf(ly - 63.5f);
                if (d < 60) set(x, y, 60, 60, 230, 255);
            } else {
                set(x, y, 255, 255, 255, 128);
            }
        }
    }

    D3D11_TEXTURE2D_DESC td{};
    td.Width = S; td.Height = S;
    td.MipLevels = 1; td.ArraySize = 1;
    td.Format = DXGI_FORMAT_B8G8R8A8_UNORM;
    td.SampleDesc.Count = 1;
    td.Usage = D3D11_USAGE_IMMUTABLE;

Урок 6. Батчинг: 10 000 спрайтов за 1 draw call

Урок 6. Батчинг: 10 000 спрайтов за 1 draw call

Без батчинга 2D-рендер мёртв. Один шейдер на всё, один VB, один IB — минимальные state-изменения.

6.1. Стоимость draw call

5–20 мкс на вызов (валидация, сборка команд, отправка в ring buffer). 10 000 спрайтов = 50–1000 мс только на CPU-overhead. Отсюда «неиграбельно».

Идея: копим вершины за кадр в один VB, группируем по (SRV, sampler), отправляем минимум draw call'ов. Целевая метрика: 10 000 спрайтов из одного атласа → 1 draw call.

6.7. EndFrame — flush

void RenderContext2D::EndFrame() {
    if (m_mappedVB) {
        m_context->Unmap(m_dynVB.Get(), 0);
        m_mappedVB = nullptr;
    }

    if (m_commands.empty()) return;
    // Setup pipeline ОДИН раз
    m_context->IASetInputLayout(m_il.Get());
    UINT stride = sizeof(Vertex), offset = 0;
    ID3D11Buffer* vbs[] = { m_dynVB.Get() };
    m_context->IASetVertexBuffers(0, 1, vbs, &stride, &offset);
    m_context->IASetIndexBuffer(m_staticIB.Get(), DXGI_FORMAT_R32_UINT, 0);
    m_context->IASetPrimitiveTopology(D3D11_PRIMITIVE_TOPOLOGY_TRIANGLELIST);

    ID3D11Buffer* cbs[] = { m_cbFrame.Get() };
    m_context->VSSetConstantBuffers(0, 1, cbs);
    m_context->PSSetConstantBuffers(0, 1, cbs);
    m_context->VSSetShader(m_vs.Get(), nullptr, 0);
    m_context->PSSetShader(m_ps.Get(), nullptr, 0);

    for (const auto& cmd : m_commands) {
        if (cmd.indexCount == 0) continue;
        m_context->PSSetShaderResources(0, 1, &cmd.srv);
        ID3D11SamplerState* s[] = { cmd.sampler };
        m_context->PSSetSamplers(0, 1, s);
        m_context->DrawIndexed(cmd.indexCount, cmd.firstIndex, 0);
        m_stats.drawCalls++;
    }

    m_commands.clear();
    m_vertexCursor = 0;
}

6.8. AddQuad — ключ батча

void RenderContext2D::AddQuad(
    const XMFLOAT2& p0, const XMFLOAT2& p1,
    const XMFLOAT2& p2, const XMFLOAT2& p3,
    const XMFLOAT2& uvMin, const XMFLOAT2& uvMax,
    ID3D11ShaderResourceView* srv,
    ID3D11SamplerState* sampler,
    const XMFLOAT4& color)
{
    if (!m_mappedVB || m_vertexCursor + 4 > kMaxVertices) return;

    // Начинаем новый батч при смене (SRV, sampler)
    bool newBatch = m_commands.empty()
        || m_commands.back().srv     != srv
        || m_commands.back().sampler != sampler;

    if (newBatch) {
        DrawCommand cmd;
        cmd.srv        = srv;
        cmd.sampler    = sampler;
        cmd.firstIndex = (m_vertexCursor / 4) * 6;
        cmd.indexCount = 0;
        m_commands.push_back(cmd);
    }

    Vertex* v = m_mappedVB + m_vertexCursor;
    v[0] = { p0, uvMin,                 color };
    v[1] = { p1, { uvMax.x, uvMin.y },  color };
    v[2] = { p2, { uvMin.x, uvMax.y },  color };
    v[3] = { p3, uvMax,                 color };
    m_vertexCursor += 4;

    m_commands.back().indexCount += 6;
    m_stats.quads++;
}

6.9. Сохранение порядка

Мы НЕ сортируем. Порядок вызовов FillRect/DrawSprite сохраняется. Это обязательно для 2D: полупрозрачные слои смешиваются в порядке отрисовки.

7.4. Растеризация глифа

bool Font::RasterizeGlyph(uint32_t cp, Glyph& out) {
    MAT2 mat = {};
    mat.eM11.value = 1; mat.eM22.value = 1;

    GLYPHMETRICS gm{};
    DWORD size = GetGlyphOutlineW(m_hdc, cp, GGO_GRAY4_BITMAP,
                                  &gm, 0, nullptr, &mat);
    if (size == GDI_ERROR  gm.gmBlackBoxX == 0  gm.gmBlackBoxY == 0) {
        // Пробел / отсутствующий
        out = {};
        out.advance = float(gm.gmCellIncX);
        return true;
    }

    UINT stride = (gm.gmBlackBoxX + 3) & ~3;
    if (!AllocAtlasRect(gm.gmBlackBoxX, gm.gmBlackBoxY, out.u0, out.v0)) return false;

    std::vector<uint8_t> buf(size);
    GetGlyphOutlineW(m_hdc, cp, GGO_GRAY4_BITMAP, &gm, size, buf.data(), &mat);

    for (UINT y = 0; y < gm.gmBlackBoxY; ++y) {
        for (UINT x = 0; x < gm.gmBlackBoxX; ++x) {
            uint8_t a = buf[y * stride + x];
            a = uint8_t(fminf(255.0f, a * 17.0f));

            // Premultiplied: белый (255) * a/255 = a
            size_t idx = (size_t(out.v0) + y) * kAtlasSize * 4
                       + (size_t(out.u0) + x) * 4;
            m_atlasPixels[idx + 0] = a;  // R
            m_atlasPixels[idx + 1] = a;  // G
            m_atlasPixels[idx + 2] = a;  // B
            m_atlasPixels[idx + 3] = a;  // A
        }
    }

    out.w        = float(gm.gmBlackBoxX);
    out.h        = float(gm.gmBlackBoxY);
    out.bearingX = float(gm.gmptGlyphOrigin.x);
    out.bearingY = float(gm.gmptGlyphOrigin.y);  // от baseline вверх
    out.advance  = float(gm.gmCellIncX);

    out.u0 /= float(kAtlasSize);
    out.v0 /= float(kAtlasSize);
    out.u1 = out.u0 + float(gm.gmBlackBoxX) / float(kAtlasSize);
    out.v1 = out.v0 + float(gm.gmBlackBoxY) / float(kAtlasSize);
    return true;
}
Premultiplied-трюк: белый текст в premultiplied — (a, a, a, a). Один байт заполняет все 4 компонента. Потом tint * color в шейдере даст нужный цвет.

    float penX = x, penY = baselineY;
    Color pc = { color.r*color.a, color.g*color.a, color.b*color.a, color.a };

    bool canSnap = snapToPixel && IsTranslationOnly(m_transform);

    while (*text) {
        uint32_t cp = (uint32_t)*text++;
        if (cp == L'\n') {
            penX = x;
            penY += font.LineHeight() * lineHeightMult;
            continue;
        }
        if (cp == L'\r') continue;

        const Glyph* g = font.GetGlyph(cp);
        if (!g) continue;

        float drawX = penX, drawY = penY;
        if (canSnap) {
            drawX = floorf(drawX + 0.5f);
            drawY = floorf(drawY + 0.5f);
        }

        if (g->w > 0 && g->h > 0) {
            float qx = drawX + g->bearingX;
            float qy = drawY - g->bearingY;    // bearingY — вверх от baseline

            AddQuad(TransformPoint(qx, qy),
                    TransformPoint(qx + g->w, qy),
                    TransformPoint(qx, qy + g->h),
                    TransformPoint(qx + g->w, qy + g->h),
                    { g->u0, g->v0 }, { g->u1, g->v1 },
                    font.AtlasSRV(), m_samplerLinear.Get(),
                    { pc.r, pc.g, pc.b, pc.a });
        }

        penX += g->advance;
        if (penX > result.width) result.width = penX;
    }
    result.width -= x;
    return result;
}

Урок 8. SDF-фигуры: геометрия без геометрии

Урок 8. SDF-фигуры: геометрия без геометрии

Signed Distance Field — фигура через формулу в PS, без единого треугольника. Идеальный AA через fwidth, батчинг сохранён.

8.1. Что такое SDF

SDF — функция d(p): для точки p возвращает расстояние до границы фигуры. d > 0 — снаружи, d = 0 — на границе, d < 0 — внутри.

Для круга радиуса r в центре:

d(p) = length(p) - r

Идея: одна и та же структура (quad из 4 вершин) рисует любую фигуру. Разница — в формуле в PS.

Плюсы:

  • Нет CPU-геометрии — 10 000 кругов = 40 000 вершин, 1 draw call.
  • AA бесплатно через fwidth — не нужен MSAA для SDF.
  • Масштабирование и трансформация бесплатно — fwidth подстроит AA под экранный масштаб.
  • Все SDF используют 1×1 white текстуру → батчатся вместе.
  • Комбинирование через min/max: min(d1, d2) — union, max(-d1, -d2) — intersection.

Ограничение: SDF — не замена ID2D1PathGeometry. Для произвольных контуров — Урок 9. SDF — для параметрических примитивов.

8.2. Формулы SDF

// Круг/диск
float sdCircle(float2 p, float r) {
    return length(p) - r;
}

// Прямоугольник: half-extent b
float sdBox(float2 p, float2 b) {
    float2 d = abs(p) - b;
    return length(max(d, 0)) + min(max(d.x, d.y), 0);
}

// Скруглённый прямоугольник
float sdRoundedBox(float2 p, float2 b, float r) {
    float2 q = abs(p) - b + r;
    return min(max(q.x, q.y), 0) + length(max(q, 0)) - r;
}

// Отрезок-капсула: расстояние до линии минус half_thickness
float sdSegment(float2 p, float2 a, float2 b) {
    float2 pa = p - a, ba = b - a;
    float l2 = dot(ba, ba);
    float h = (l2 > 1e-6) ? saturate(dot(pa, ba) / l2) : 0.0;
    return length(pa - ba * h);
}

// Кольцо
d = abs(sdCircle(p, r)) - halfThickness

8.3. Как из SDF получить пиксель

float aa   = fwidth(d);              // ~1 экранный пиксель в локальных единицах
float fill = saturate(0.5 - d / aa); // 1 внутри, 0 снаружи, плавно на границе

// Premultiplied:
return float4(color.rgb * fill, color.a * fill);

Магия fwidth: fwidth(d) = |ddx(d)| + |ddy(d)| — сумма абсолютных производных. Показывает «сколько локальных единиц в одном экранном пикселе». Значит AA-полоса — всегда 1 физический пиксель, независимо от масштаба, поворота, DPI.

float4 PSMain(VSOut i) : SV_Target {
    uint t = (uint)i.shape.x;

    if (t == 0u) {
        // Обычный спрайт
        return g_tex.Sample(g_samp, i.uv) * i.col;
    }

    float2 halfExt = i.shape.yz;
    float2 p = (i.uv - 0.5) * 2.0 * halfExt;

    float d;
    if (t == 1u) {
        d = sdCircle(p, i.shape.w);
    } else if (t == 2u) {
        d = sdBox(p, float2(i.shape.w, i.params.x));
    } else if (t == 3u) {
        d = sdRoundedBox(p, float2(i.shape.w, i.params.x), i.params.y);
    } else if (t == 4u) {
        float2 a = float2(i.shape.w, i.params.x);
        float2 b = float2(i.params.y, i.params.z);
        d = sdSegment(p, a, b) - i.params.w;
    } else if (t == 5u) {
        d = abs(sdCircle(p, i.shape.w)) - i.params.x;
    } else {
        return float4(0, 0, 0, 0);
    }

    float aa = fwidth(d);
    float fill = saturate(0.5 - d / aa);
    return float4(i.col.rgb * fill, i.col.a * fill);
}
Не делай early-return для SDF-типов. fwidth — derivative instruction, требует, чтобы все потоки warp'а прошли через неё. С early-return может случиться «gradient instruction in divergent flow». Структура выше правильна: если внутри SDF — без early-return, общий AA в конце.

9.1. Cubic Bezier

B(t) = (1-t)³ P0 + 3(1-t)²t P1 + 3(1-t)t² P2 + t³ P3

Cubic — стандарт в SVG/PostScript/TTF. Quadratic (3 точки) превращается в cubic:

Q: P0, P1, P2  →  C: P0,
                    P0 + 2/3 (P1 - P0),
                    P2 + 2/3 (P1 - P2),
                    P2

9.2. De Casteljau + adaptive flatten

Идея: если кривая почти прямая — заменяем отрезком. Иначе — делим пополам (de Casteljau at t=0.5) и рекурсируем.

FlattenCubic
void FlattenCubic(XMFLOAT2 p0, XMFLOAT2 p1, XMFLOAT2 p2, XMFLOAT2 p3,
                  float tolerance, std::vector<XMFLOAT2>& out,
                  int depth = 0)
{
    if (depth > 16) { out.push_back(p3); return; }   // защита от рекурсии

    float dx = p3.x - p0.x, dy = p3.y - p0.y;
    float len2 = dx*dx + dy*dy;
    if (len2 < 1e-6f) { out.push_back(p3); return; }

    auto distToLine = [&](XMFLOAT2 p) {
        float cross = (p.x - p0.x) * dy - (p.y - p0.y) * dx;
        return fabsf(cross) / sqrtf(len2);
    };

    if (distToLine(p1) <= tolerance && distToLine(p2) <= tolerance) {
        out.push_back(p3);
        return;
    }

    // Split de Casteljau at t=0.5
    XMFLOAT2 a = { (p0.x + p1.x) * 0.5f, (p0.y + p1.y) * 0.5f };
    XMFLOAT2 b = { (p1.x + p2.x) * 0.5f, (p1.y + p2.y) * 0.5f };
    XMFLOAT2 c = { (p2.x + p3.x) * 0.5f, (p2.y + p3.y) * 0.5f };
    XMFLOAT2 d = { (a.x + b.x) * 0.5f, (a.y + b.y) * 0.5f };
    XMFLOAT2 e = { (b.x + c.x) * 0.5f, (b.y + c.y) * 0.5f };
    XMFLOAT2 f = { (d.x + e.x) * 0.5f, (d.y + e.y) * 0.5f };

    FlattenCubic(p0, a, d, f, tolerance, out, depth + 1);
    FlattenCubic(f, e, c, p3, tolerance, out, depth + 1);
}

tolerance = 0.25 — стандарт. Средняя кривая даёт 4–16 сегментов. S-образная — до 64. Для UI-иконок редко > 100.

9.4. Ear clipping — триангуляция

Классический алгоритм для простых (без самопересечений) полигонов. O(n²). Отверстия (holes) — не поддерживает.

static float Cross2D(XMFLOAT2 a, XMFLOAT2 b, XMFLOAT2 c) {
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x);
}

static bool PointInTriangle(XMFLOAT2 p, XMFLOAT2 a, XMFLOAT2 b, XMFLOAT2 c) {
    float d1 = Cross2D(a, b, p);
    float d2 = Cross2D(b, c, p);
    float d3 = Cross2D(c, a, p);
    bool neg = (d1 < 0) || (d2 < 0) || (d3 < 0);
    bool pos = (d1 > 0) || (d2 > 0) || (d3 > 0);
    return !(neg && pos);
}

std::vector<uint32_t> TriangulatePolygon(std::vector<XMFLOAT2> pts) {
    std::vector<uint32_t> tris;
    int n = (int)pts.size();
    if (n < 3) return tris;

    // Ориентация → CCW
    float area = 0;
    for (int i = 0; i < n; ++i) {
        int j = (i + 1) % n;
        area += pts[i].x * pts[j].y - pts[j].x * pts[i].y;
    }
    if (area < 0) std::reverse(pts.begin(), pts.end());

    std::vector<int> idx(n);
    for (int i = 0; i < n; ++i) idx[i] = i;

    int guard = n * n;
    while ((int)idx.size() > 2 && guard-- > 0) {
        bool foundEar = false;

        for (size_t i = 0; i < idx.size(); ++i) {
            int ip = idx[(i + idx.size() - 1) % idx.size()];
            int ic = idx[i];
            int in = idx[(i + 1) % idx.size()];

            XMFLOAT2 a = pts[ip], b = pts[ic], c = pts[in];
            if (Cross2D(a, b, c) <= 0) continue;   // concave

            bool containsOther = false;
            for (size_t j = 0; j < idx.size(); ++j) {
                if ((int)j == (int)i
                 || idx[j] == ip || idx[j] == ic || idx[j] == in) continue;
                if (PointInTriangle(pts[idx[j]], a, b, c)) {
                    containsOther = true;
                    break;
                }
            }
            if (containsOther) continue;

            // Ухо
            tris.push_back(ip);
            tris.push_back(ic);
            tris.push_back(in);
            idx.erase(idx.begin() + i);
            foundEar = true;
            break;
        }
        if (!foundEar) break;   // вырожденный полигон
    }
    return tris;
}

void RenderContext2D::StrokePolyline(const std::vector<XMFLOAT2>& pts,
                                     bool closed, float thickness, Color c)
{
    if (pts.size() < 2) return;
    float r = thickness * 0.5f;

    size_t n = pts.size();
    size_t segCount = closed ? n : n - 1;
    for (size_t i = 0; i < segCount; ++i) {
        const auto& a = pts[i];
        const auto& b = pts[(i + 1) % n];
        DrawLine(a.x, a.y, b.x, b.y, thickness, c);
    }

    // Round joins на внутренних точках
    size_t joinStart = 1;
    size_t joinEnd   = closed ? n : n - 1;
    for (size_t i = joinStart; i < joinEnd; ++i) {
        FillCircle(pts[i].x, pts[i].y, r, c);
    }

    // Round caps на концах
    if (!closed) {
        FillCircle(pts.front().x, pts.front().y, r, c);
        FillCircle(pts.back().x,  pts.back().y,  r, c);
    }
}

10.4. EvalBrush — единый цвет в PS

struct BrushData {
    float4 c0;
    float4 c1;
    float4 p0;
    uint   type;
    uint3  _pad;
};

StructuredBuffer<BrushData> g_brushes : register(t1);

float4 EvalBrush(uint brushId, float2 uv, float4 fallbackColor) {
    BrushData b = g_brushes[brushId];

    if (b.type == 0u) return fallbackColor;   // solid = i.col

    if (b.type == 1u) {
        // linear: p0.xy = startUV, p0.zw = endUV
        float2 dir = b.p0.zw - b.p0.xy;
        float len2 = dot(dir, dir);
        float t = (len2 > 1e-6) ? saturate(dot(uv - b.p0.xy, dir) / len2) : 0.0;
        return lerp(b.c0, b.c1, t);
    }

    if (b.type == 2u) {
        // radial: p0.xy = centerUV, p0.z = radiusUV
        float r = max(b.p0.z, 1e-6);
        float t = saturate(length(uv - b.p0.xy) / r);
        return lerp(b.c0, b.c1, t);
    }
    return fallbackColor;
}

    m_transform = m;    // ЗАМЕНА, не композиция
}

}

void RenderContext2D::PushTransform(const XMMATRIX& m) {
    m_transformStack.push_back(m_transform);
    m_transform = XMMatrixMultiply(m, m_transform);   // m * current
}

void RenderContext2D::PopTransform() {
    if (!m_transformStack.empty()) {
        m_transform = m_transformStack.back();
        m_transformStack.pop_back();
    }
}

struct DrawState {
    XMMATRIX transform;
    XMFLOAT4 clipRect;
    bool     hasClip;
};

DrawState RenderContext2D::SaveState() const {
    DrawState s;
    s.transform = m_transform;
    if (m_clipStack.empty()) {
        s.hasClip = false;
        s.clipRect = { 0, 0, (float)m_widthPx / m_dpiScale,
                             (float)m_heightPx / m_dpiScale };
    } else {
        s.hasClip = true;
        s.clipRect = m_clipStack.back();
    }
    return s;
}

void RenderContext2D::RestoreState(const DrawState& s) {
    m_transform = s.transform;
    m_clipStack.clear();
    if (s.hasClip) m_clipStack.push_back(s.clipRect);
}

void RenderContext2D::PushAxisAlignedClip(float x, float y, float w, float h) {
    XMFLOAT4 newClip = { x, y, w, h };
    if (!m_clipStack.empty()) {
        // Пересечение с текущим
        const XMFLOAT4& cur = m_clipStack.back();
        float nx = maxf(x, cur.x);
        float ny = maxf(y, cur.y);
        float nw = minf(x + w, cur.x + cur.z) - nx;
        float nh = minf(y + h, cur.y + cur.w) - ny;
        if (nw < 0) nw = 0;
        if (nh < 0) nh = 0;
        newClip = { nx, ny, nw, nh };
    }
    m_clipStack.push_back(newClip);
}

12.4. Вычисление D3D11_RECT

D3D11_RECT RenderContext2D::ComputeScissor() const {
    float W = (float)m_widthPx;
    float H = (float)m_heightPx;

    if (m_clipStack.empty()) return { 0, 0, (LONG)W, (LONG)H };

    const XMFLOAT4& c = m_clipStack.back();
    float l = c.x * m_dpiScale;
    float t = c.y * m_dpiScale;
    float r = (c.x + c.z) * m_dpiScale;
    float b = (c.y + c.w) * m_dpiScale;

    // Snap: floor левого-верхнего, ceil правого-нижнего (перекрыть полный пиксель)
    LONG L = (LONG)floorf(l);
    LONG T = (LONG)floorf(t);
    LONG R = (LONG)ceilf(r);
    LONG B = (LONG)ceilf(b);

    // Clamp к back-buffer
    if (L < 0) L = 0;
    if (T < 0) T = 0;
    if (R > (LONG)W) R = (LONG)W;
    if (B > (LONG)H) B = (LONG)H;
    if (R < L) R = L;
    if (B < T) B = T;

    return { L, T, R, B };
}

struct LayerRTT {

void RenderContext2D::CreateLayerRTTs() {
    for (int i = 0; i < kMaxLayers; ++i) {
        auto& lr = m_layerRTTs[i];
        lr.rtv.Reset(); lr.srv.Reset(); lr.texture.Reset();
        lr.busy = false;

        D3D11_TEXTURE2D_DESC td{};
        td.Width = m_widthPx; td.Height = m_heightPx;
        td.MipLevels = 1; td.ArraySize = 1;
        td.Format = DXGI_FORMAT_B8G8R8A8_UNORM;
        td.SampleDesc.Count = 1;   // без MSAA (нужен SRV)
        td.Usage = D3D11_USAGE_DEFAULT;
        td.BindFlags = D3D11_BIND_RENDER_TARGET | D3D11_BIND_SHADER_RESOURCE;

        m_device->CreateTexture2D(&td, nullptr, &lr.texture);
        m_device->CreateRenderTargetView(lr.texture.Get(), nullptr, &lr.rtv);
        m_device->CreateShaderResourceView(lr.texture.Get(), nullptr, &lr.srv);

}

12.8. PushLayer

void RenderContext2D::PushLayer(float opacity) {
    if ((int)m_layerStack.size() >= kMaxLayers) return;

    FlushBatch();   // накопленное — в текущий target

    int slot = -1;
    for (int i = 0; i < kMaxLayers; ++i) {
        if (!m_layerRTTs[i].busy) { slot = i; break; }
    }
    if (slot < 0) return;

    LayerContext ctx;
    ctx.savedRTV = m_rtv;
    ctx.savedClipStack = m_clipStack;
    ctx.savedTransform = m_transform;
    ctx.rttSlot = slot;
    ctx.opacity = opacity;
    ctx.vertexCursorAtStart = m_vertexCursor;
    m_layerStack.push_back(std::move(ctx));

    auto& lr = m_layerRTTs[slot];
    lr.busy = true;
    m_rtv = lr.rtv;

    ID3D11RenderTargetView* rtv = lr.rtv.Get();
    m_context->OMSetRenderTargets(1, &rtv, nullptr);
    const float clear[4] = {0, 0, 0, 0};
    m_context->ClearRenderTargetView(rtv, clear);

    D3D11_VIEWPORT vp{ 0, 0, (float)m_widthPx, (float)m_heightPx, 0, 1 };
    m_context->RSSetViewports(1, &vp);
}

12.9. PopLayer

void RenderContext2D::PopLayer() {
    if (m_layerStack.empty()) return;

    FlushBatch();   // содержимое слоя — в layerRTT

    LayerContext ctx = std::move(m_layerStack.back());
    m_layerStack.pop_back();

    // Возврат
    m_rtv = ctx.savedRTV;
    ID3D11RenderTargetView* rtv = m_rtv.Get();
    m_context->OMSetRenderTargets(1, &rtv, nullptr);
    D3D11_VIEWPORT vp{ 0, 0, (float)m_widthPx, (float)m_heightPx, 0, 1 };
    m_context->RSSetViewports(1, &vp);

    m_clipStack = std::move(ctx.savedClipStack);

    // Пустой слой → пропускаем композицию
    if (m_vertexCursor == ctx.vertexCursorAtStart) {
        m_layerRTTs[ctx.rttSlot].busy = false;
        return;
    }

    // Композиция: full-screen quad без transform
    XMMATRIX savedTransform = m_transform;
    m_transform = XMMatrixIdentity();

    float W = (float)m_widthPx / m_dpiScale;
    float H = (float)m_heightPx / m_dpiScale;
    XMFLOAT4 tint = { ctx.opacity, ctx.opacity, ctx.opacity, ctx.opacity };

    AddQuad({0,0}, {W,0}, {0,H}, {W,H}, {0,0}, {1,1},
            m_layerRTTs[ctx.rttSlot].srv.Get(),
            m_samplerLinear.Get(), tint,
            {0,0,0,0}, {0,0,0,0}, 0);

    m_transform = savedTransform;
    m_layerRTTs[ctx.rttSlot].busy = false;
}

13.4. SDF-текст

GDI-битмапы из Урока 7 мылят при масштабировании. SDF-текст — distance field в texel'ах, при рендере smoothstep даёт идеальный край на любом масштабе.

Формат

sdf = clamp(distance_to_edge / (2 * spread) + 0.5, 0, 1)

Внутри глифа — >0.5, снаружи — <0.5, на границе — 0.5. spread = 4–8 пикселей исходного размера.

Генерация (bruteforce)

static void GenerateSDF(const uint8_t* srcBitmap, int w, int h,
                        uint8_t* outSDF, float spread)
{
    // 1. Извлекаем контур (пиксели, где alpha пересекает 0.5)
    std::vector<float> edges;
    for (int y = 0; y < h; ++y) {
        for (int x = 0; x < w; ++x) {
            if (x == 0 || x == w - 1 || y == 0 || y == h - 1) continue;
            uint8_t c = srcBitmap[y * w + x];
            bool inside = c > 127;
            bool isEdge = false;
            for (int dy = -1; dy <= 1 && !isEdge; ++dy) {
                for (int dx = -1; dx <= 1 && !isEdge; ++dx) {
                    if (dx == 0 && dy == 0) continue;
                    uint8_t n = srcBitmap[(y + dy) * w + (x + dx)];
                    if (inside != (n > 127)) isEdge = true;
                }
            }
            if (isEdge) { edges.push_back(float(x)); edges.push_back(float(y)); }
        }
    }

    // 2. Для каждого пикселя — минимальное расстояние
    for (int y = 0; y < h; ++y) {
        for (int x = 0; x < w; ++x) {
            float minDist = spread;
            for (size_t i = 0; i < edges.size(); i += 2) {
                float dx = edges[i] - x;
                float dy = edges[i + 1] - y;
                float d2 = dx*dx + dy*dy;
                if (d2 < minDist * minDist) minDist = sqrtf(d2);
            }
            bool inside = srcBitmap[y * w + x] > 127;
            float signedDist = inside ? -minDist : minDist;
            float v = (signedDist / (2.0f * spread)) + 0.5f;
            outSDF[y * w + x] = (uint8_t)(saturatef(v) * 255.0f + 0.5f);
        }
    }
}

O(w × h × edges) — для 64×64 глифа с 200 edge-пикселями ~800K операций. На 256 глифов — 200M. Медленно, но одноразово. Для продакшена — Felzenszwalb O(w × h), в 100 раз быстрее.

PS для SDF-текста

13.6. Gamma

Мониторы физически нелинейны: intensity = pow(value, 2.2) для sRGB. Хранение в 8-bit sRGB делает восприятие равномерным, но blending работает неправильно.

Пример: 50% белого на 50% чёрном.

Naive sRGB:  (1.0 + 0.0) / 2 = 0.5    → на экране 50% яркости
Правильно:   pow((pow(1,2.2)+pow(0,2.2))/2, 1/2.2) ≈ 0.73  → 73% яркости
Для UI: sRGB blend — default. Так работают Photoshop/Figma, пользователь ожидает это. Не меняй на linear — станет «странно».

Option: _SRGB format

// Swap chain:

// RTV:
D3D11_RENDER_TARGET_VIEW_DESC rtvd{};
rtvd.Format = DXGI_FORMAT_B8G8R8A8_UNORM_SRGB;
rtvd.ViewDimension = D3D11_RTV_DIMENSION_TEXTURE2D;

// SRV — аналогично

Blending в linear space. Градиенты без «грязного» серого. UI «контрастнее» — правильно физически, но непривычно. Для продакшена — сделай toggle в настройках.

Не смешивай hardware sRGB с ручной pow(c, 1/2.2) в PS — двойная конверсия, всё тёмное.

14.1. Модель

14.2. Ключевые правила

  1. Только render thread трогает ID3D11DeviceContext. Map, Draw, Present, ResizeBuffers, ClearState.
  2. Main thread — никогда не блокируется на VSync. Строит кадр, отправляет, идёт дальше.
  3. FontData/SpriteData/BrushStore — CPU-side, immutable, thread-safe для чтения.
  4. FontGPU/SpriteGPU — device resources, только render thread, lazy create + recreate при device lost.
  5. DrawList — value-объект (plain data), передаётся через Submit.

14.4. FontData — CPU, thread-safe

struct GlyphInfo {
    float u0, v0, u1, v1;   // UV в атласе
    float w, h;              // размер black box
    float bearingX, bearingY;
    float advance;
};

class FontData {
public:
    bool Load(const wchar_t* face, int pixelHeight, bool bold);

    const GlyphInfo* GetGlyph(uint32_t cp) const {
        auto it = m_glyphs.find(cp);
        return it == m_glyphs.end() ? nullptr : &it->second;
    }

    TextMetrics Measure(const wchar_t* text, float lineHeightMult = 1.0f) const {
        float penX = 0, maxX = 0, penY = 0;
        while (*text) {
            uint32_t cp = *text++;
            if (cp == L'\n') { penY += LineHeight() * lineMult; maxX = max(maxX, penX); penX = 0; continue; }
            if (cp == L'\r') continue;
            if (auto* g = GetGlyph(cp)) penX += g->advance;
        }
        maxX = max(maxX, penX);
        return { maxX, penY + LineHeight() * lineMult };
    }

    float Ascent()     const { return m_ascent; }
    float Descent()    const { return m_descent; }
    float LineHeight() const { return m_ascent + m_descent + m_lineGap; }

    const uint8_t* AtlasPixels() const { return m_atlasPixels.data(); }
    UINT AtlasSize()   const { return kAtlasSize; }

private:
    std::unordered_map<uint32_t, GlyphInfo> m_glyphs;
    std::vector<uint8_t> m_atlasPixels;   // BGRA8 premultiplied
    float m_ascent = 0, m_descent = 0, m_lineGap = 0;
    static constexpr UINT kAtlasSize = 2048;
};

struct FontGPU {
    ComPtr<ID3D11Texture2D>          atlas;
    ComPtr<ID3D11ShaderResourceView> srv;
};

Ключевое: Measure и рендер используют одну и ту же логику advance/bearing. Иначе layout разойдётся с рендером.

Пре-варм: в Load растеризовать все нужные символы сразу (ASCII 32..126 + Latin-1 160..255 + кириллица 0x400..0x4FF). Иначе первый кадр лагает и Measure может вернуть неверную ширину для не-загруженного глифа.

14.5. BrushStore — thread-safe

class BrushStore {
public:
    BrushId CreateLinearGradient(Color c0, Color c1,
                                  float x0, float y0, float x1, float y1) {
        std::lock_guard lock(m_mutex);
        BrushData b{};
        b.c0 = Premul(c0); b.c1 = Premul(c1);
        b.p0 = { x0, y0, x1, y1 };
        b.type = 1;
        if (!m_free.empty()) {
            auto id = m_free.back(); m_free.pop_back();
            m_brushes[id] = b;
            return id;
        }
        m_brushes.push_back(b);
        return BrushId(m_brushes.size() - 1);
    }

    void Release(BrushId id) {
        std::lock_guard lock(m_mutex);
        if (id == 0 || id >= m_brushes.size()) return;
        m_brushes[id].type = 0;
        m_free.push_back(id);
    }

    void Snapshot(std::vector<BrushData>& out) {
        std::lock_guard lock(m_mutex);
        out = m_brushes;
    }

private:
    std::mutex m_mutex;
    std::vector<BrushData> m_brushes{ BrushData{} };
    std::vector<BrushId>   m_free;
};

14.7. Submit — back-pressure

void RenderThread::Submit(DrawList&& list) {
    std::unique_lock lock(m_mutex);
    m_cv.wait(lock, [&] { return !m_hasWork || m_stop; });
    if (m_stop) return;

    m_pendingList = std::move(list);
    m_hasWork = true;
    m_cv.notify_all();
}

Main thread ждёт ровно один кадр render thread'а. Нет latency накопления, нет race. Single-slot очередь — идеал для UI.

14.8. ThreadLoop

void RenderThread::ThreadLoop() {
    while (true) {
        DrawList list;
        {
            std::unique_lock lock(m_mutex);
            m_cv.wait(lock, [&] { return m_hasWork || m_stop || m_recoveryPending; });

            if (m_stop) return;

            if (m_recoveryPending) {
                lock.unlock();
                RecoverDevice();
                lock.lock();
                m_recoveryPending = false;
                m_cv.notify_all();
                continue;
            }

            if (!m_hasWork) continue;

            list = std::move(m_pendingList);
            m_hasWork = false;
            m_cv.notify_all();
        }

        ProcessFrame(list);
    }
}

void RenderThread::ProcessFrame(const DrawList& list) {
    if (m_deviceLost.load()) return;

    if (m_resizePending) {
        if (!ProcessResize()) return;
        m_resizePending = false;
    }

    LARGE_INTEGER t0, t1, freq;
    QueryPerformanceCounter(&t0);
    QueryPerformanceFrequency(&freq);

    // Snapshot brush'ов (thread-safe)
    m_brushes.Snapshot(m_brushSnapshot);
    m_rc.UploadBrushes(m_brushSnapshot);

    m_rc.BeginFrame(m_rtv.Get());
    ExecuteDrawList(list);
    m_rc.EndFrame();

    HRESULT hr = m_swapChain->Present(1, 0);
    if (hr == DXGI_ERROR_DEVICE_REMOVED || hr == DXGI_ERROR_DEVICE_RESET) {
        m_deviceLost = true;
        OutputDebugStringA("DEVICE LOST in render thread\n");
        return;
    }
    if (FAILED(hr)) { m_deviceLost = true; return; }

    QueryPerformanceCounter(&t1);
    m_lastFrameTimeMs = float(t1.QuadPart - t0.QuadPart) * 1000.0f / float(freq.QuadPart);
    m_presentCount.fetch_add(1);
}

14.9. ExecuteDrawText — использует FontGPU

void RenderThread::ExecuteDrawText(const DrawCmd& cmd) {
    uint32_t fontId = cmd.resourceId;
    EnsureFontGPU(fontId);

    const FontData& fd = *m_fontsData[fontId];
    const FontGPU&  fg = m_fontsGPU[fontId];
    ID3D11ShaderResourceView* srv = fg.srv.Get();

    float penX = cmd.x;
    float penY = cmd.y;
    bool  snap = cmd.flag;
    bool  canSnap = snap && IsTranslationOnly(m_rc.GetTransform());

    const wchar_t* text = cmd.text.c_str();
    while (*text) {
        uint32_t cp = *text++;
        if (cp == L'\n') { penX = cmd.x; penY += fd.LineHeight(); continue; }
        if (cp == L'\r') continue;

        const GlyphInfo* g = fd.GetGlyph(cp);
        if (!g) continue;

        float drawX = penX, drawY = penY;
        if (canSnap) {
            XMFLOAT4X4 tm;
            XMStoreFloat4x4(&tm, m_rc.GetTransform());
            float wx = tm._41 + penX, wy = tm._42 + penY;
            wx = floorf(wx + 0.5f); wy = floorf(wy + 0.5f);
            drawX = wx - tm._41; drawY = wy - tm._42;
        }

        if (g->w > 0 && g->h > 0) {
            float qx = drawX + g->bearingX;
            float qy = drawY - g->bearingY;
            m_rc.AddTextQuad(srv, qx, qy, qx + g->w, qy + g->h,
                             g->u0, g->v0, g->u1, g->v1,
                             { cmd.color.x, cmd.color.y, cmd.color.z, cmd.color.w });
        }
        penX += g->advance;
    }
}

void RenderThread::EnsureFontGPU(uint32_t fontId) {
    if (m_fontsGPU.size() <= fontId) m_fontsGPU.resize(fontId + 1);
    if (m_fontsGPU[fontId].srv) return;

    const FontData& fd = *m_fontsData[fontId];
    UINT sz = fd.AtlasSize();

    D3D11_TEXTURE2D_DESC td{};
    td.Width = sz; td.Height = sz;
    td.MipLevels = 1; td.ArraySize = 1;
    td.Format = DXGI_FORMAT_B8G8R8A8_UNORM;
    td.SampleDesc.Count = 1;
    td.Usage = D3D11_USAGE_IMMUTABLE;
    td.BindFlags = D3D11_BIND_SHADER_RESOURCE;

    D3D11_SUBRESOURCE_DATA init{};
    init.pSysMem = fd.AtlasPixels();
    init.SysMemPitch = sz * 4;

    auto& fg = m_fontsGPU[fontId];
    m_device->CreateTexture2D(&td, &init, &fg.atlas);
    m_device->CreateShaderResourceView(fg.atlas.Get(), nullptr, &fg.srv);

bool RenderThread::ProcessResize() {
    UINT w = m_pendingW, h = m_pendingH;
    if (w == 0 || h == 0) return false;
    if (w == m_width && h == m_height) return true;

    m_rtv.Reset();
    m_context->ClearState();

    m_rc.OnResize(w, h);

    HRESULT hr = m_swapChain->ResizeBuffers(0, w, h, DXGI_FORMAT_UNKNOWN, 0);
    if (hr == DXGI_ERROR_DEVICE_REMOVED || hr == DXGI_ERROR_DEVICE_RESET) {
        m_deviceLost = true;
        return false;
    }
    if (FAILED(hr)) return false;

    if (!CreateBackBufferRTV()) return false;
    m_width = w; m_height = h;
    m_rc.OnResizeFinalize();   // projScaleBias + UpdateFrameCB
    return true;
}

Урок 15. DirectWrite interop

GDI-растр из Урока 7 не умеет арабский, деванагари, сложные лигатуры и цветные эмодзи. DirectWrite — стандартный API Windows для всего этого. Встраиваем в многопоточную архитектуру Урока 14.

Ключевая идея: DirectWrite отделяет шейпинг (какие глифы и как расположены) от рендеринга (как их нарисовать). Первое — CPU, второе — наш GPU-пайплайн.

15.2. Threading-модель DirectWrite

IDWriteFactory — thread-safe, можно создавать в main thread и использовать в любом. Но IDWriteTextLayout — immutable после создания, тоже thread-safe для чтения. Это идеально ложится на архитектуру Урока 14:

  • Main thread: CreateTextLayout, GetMetrics, GetGlyphRun — для Measure и layout.
  • Render thread: GetGlyphRun → AddQuad через SDF atlas.
  • DrawList: хранит ComPtr<IDWriteTextLayout> как shared resource. Immutable — race невозможна.
Почему не IDWriteTextLayout::Draw: этот метод требует callback-интерфейс IDWriteTextRenderer, который рисует через GDI/D2D. Мы хотим сами управлять GPU, поэтому идём через GetGlyphRun — получаем массив индексов глифов + позиции, а рисуем сами.

15.6. SDF-генерация глифа

DirectWrite умеет растеризовать глиф с DWRITE_RENDERING_MODE_NATURAL_SYMMETRIC — получаем grayscale AA. Дальше — distance transform (Урок 13) даёт SDF.

bool DWriteFontData::RasterizeSDF(uint16_t glyphIndex, DWriteGlyphInfo& out) {
    // 1. Получить glyph metrics
    DWRITE_GLYPH_METRICS gm{};
    if (FAILED(m_face->GetDesignGlyphMetrics(&glyphIndex, 1, &gm, FALSE)))
        return false;

    float scale = m_baseSizePx / m_designUnitsPerEm;
    float bboxW = float(gm.advanceWidth) * scale;
    float bearingX = float(gm.leftSideBearing) * scale;
    float bearingY = float(gm.topSideBearing) * scale;

    // 2. Растеризация с pad (spread) по краям
    int pad = int(m_spread + 0.5f);
    int w = int(gm.advanceWidth * scale) + pad * 2;
    int h = int(m_baseSizePx) + pad * 2;
    if (w <= 0 || h <= 0) return false;

    std::vector<uint8_t> bitmap(w * h, 0);

    DWRITE_GLYPH_RUN run{};
    run.fontFace = m_face.Get();
    run.fontEmSize = m_baseSizePx;
    run.glyphIndices = &glyphIndex;
    run.glyphAdvances = nullptr;
    run.glyphOffsets = nullptr;
    run.glyphCount = 1;
    run.isSideways = FALSE;
    run.bidiLevel = 0;

    RECT bbox{ 0, 0, w, h };
    DWRITE_MATRIX matrix{ 1, 0, 0, 1, float(pad), float(pad) };

    if (FAILED(m_face->GetGdiCompatibleGlyphMetrics(m_baseSizePx, 1.0f, nullptr,
                                                     TRUE, &glyphIndex, 1, &gm, FALSE)))
        return false;

    // Через CreateGlyphRunAnalysis (даёт grayscale raster)
    ComPtr<IDWriteGlyphRunAnalysis> analysis;
    ComPtr<IDWriteFactory> factory;
    m_face->GetFactory(&factory);

    DWRITE_RENDERING_MODE renderMode = DWRITE_RENDERING_MODE_NATURAL_SYMMETRIC;
    if (FAILED(factory->CreateGlyphRunAnalysis(
            &run, 1.0f, &matrix, renderMode,
            DWRITE_MEASURING_MODE_NATURAL,
            0.0f, 0.0f, &analysis))) return false;

    // Получить alpha texture
    RECT fullRect;
    analysis->GetAlphaTextureBounds(DWRITE_TEXTURE_ALIASED_1x1, &fullRect);

    UINT texW = fullRect.right - fullRect.left;
    UINT texH = fullRect.bottom - fullRect.top;
    if (texW == 0 || texH == 0) return false;

    std::vector<uint8_t> alpha(texW * texH);
    if (FAILED(analysis->CreateAlphaTexture(DWRITE_TEXTURE_ALIASED_1x1,
            &fullRect, alpha.data(), UINT(alpha.size())))) return false;

    // 3. Distance transform (bruteforce — Урок 13)
    //    Simplified: ищем минимальное расстояние до границы
    std::vector<uint8_t> sdf(texW * texH);
    GenerateSDF(alpha.data(), texW, texH, sdf.data(), m_spread);

    // 4. Упаковать в атлас
    UINT atlasX, atlasY;
    if (!AllocAtlasRect(texW, texH, atlasX, atlasY)) return false;

    for (UINT y = 0; y < texH; ++y) {
        for (UINT x = 0; x < texW; ++x) {
            m_atlasPixels[(atlasY + y) * kAtlasSize + (atlasX + x)] =
                sdf[y * texW + x];
        }
    }

    // 5. Glyph info
    out.w        = float(texW);
    out.h        = float(texH);
    out.bearingX = bearingX - float(pad);
    out.bearingY = bearingY + float(pad);
    out.advance  = float(gm.advanceWidth) * scale;
    out.u0 = float(atlasX) / kAtlasSize;
    out.v0 = float(atlasY) / kAtlasSize;
    out.u1 = out.u0 + float(texW) / kAtlasSize;
    out.v1 = out.v0 + float(texH) / kAtlasSize;

    return true;
}

void PostProcess::CreateSceneRTT() {
    D3D11_TEXTURE2D_DESC td{};

    td.Height = m_height;

    rtvd.Format = DXGI_FORMAT_B8G8R8A8_UNORM_SRGB;
    rtvd.ViewDimension = D3D11_RTV_DIMENSION_TEXTURE2D;

    // SRV в _SRGB
    D3D11_SHADER_RESOURCE_VIEW_DESC srvd{};
    srvd.Format = DXGI_FORMAT_B8G8R8A8_UNORM_SRGB;
    srvd.ViewDimension = D3D11_SRV_DIMENSION_TEXTURE2D;
    m_device->CreateShaderResourceView(m_sceneTex.Get(), &srvd, &m_sceneSRV);

sRGB в сцене: PS пишет linear, RTV автоматически конвертирует в sRGB (pow 1/2.2). SRV читает sRGB, конвертирует в linear (pow 2.2) при Sample. Так вся цепочка bloom/tonemap работает в linear space — правильно физически.

16.5. Bloom — extract bright

Texture2D    g_scene : register(t0);
SamplerState g_samp  : register(s0);

    float threshold;
    float3 _pad;

float4 PSExtract(VSOut i) : SV_Target {
    float3 c = g_scene.Sample(g_samp, i.uv).rgb;
    // Если luminance > threshold — оставляем, иначе 0
    float lum = dot(c, float3(0.2126, 0.7152, 0.0722));
    float factor = max(0, lum - threshold) / max(lum, 1e-5);
    return float4(c * factor, 1);
}

16.6. Bloom — downsample (5 уровней)

float4 PSDownsample(VSOut i) : SV_Target {
    float2 texel = 1.0 / float2(width, height);

    // 4-tap bilinear (быстрое сглаживание)
    float3 c = 0;
    c += g_input.Sample(g_samp, i.uv + texel * float2(-1, -1)).rgb;
    c += g_input.Sample(g_samp, i.uv + texel * float2( 1, -1)).rgb;
    c += g_input.Sample(g_samp, i.uv + texel * float2(-1,  1)).rgb;
    c += g_input.Sample(g_samp, i.uv + texel * float2( 1,  1)).rgb;
    return float4(c * 0.25, 1);
}

Каждый уровень — половина предыдущего. 5 уровней: W/2, W/4, W/8, W/16, W/32. Итого для 1920×1080: 960×540, 480×270, ... Мизер по памяти (суммарно ~1.5 МБ на все уровни).

16.7. Bloom — upsample composite

float4 PSUpsample(VSOut i) : SV_Target {
    float2 texel = 1.0 / float2(lowResW, lowResH);

    // 9-tap gaussian (approximation)
    float3 c = 0;
    c += g_low .Sample(g_samp, i.uv + texel * float2(-1, -1)).rgb * 0.0625;
    c += g_low .Sample(g_samp, i.uv + texel * float2( 0, -1)).rgb * 0.1250;
    c += g_low .Sample(g_samp, i.uv + texel * float2( 1, -1)).rgb * 0.0625;
    c += g_low .Sample(g_samp, i.uv + texel * float2(-1,  0)).rgb * 0.1250;
    c += g_low .Sample(g_samp, i.uv + texel * float2( 0,  0)).rgb * 0.2500;
    c += g_low .Sample(g_samp, i.uv + texel * float2( 1,  0)).rgb * 0.1250;
    c += g_low .Sample(g_samp, i.uv + texel * float2(-1,  1)).rgb * 0.0625;
    c += g_low .Sample(g_samp, i.uv + texel * float2( 0,  1)).rgb * 0.1250;
    c += g_low .Sample(g_samp, i.uv + texel * float2( 1,  1)).rgb * 0.0625;

    // Add к предыдущему уровню (bloom composite)
    float3 upper = g_upper.Sample(g_samp, i.uv).rgb;
    return float4(upper + c, 1);
}

16.8. Tone mapping ACES

// ACES filmic tone mapping (Krzysztof Narkowicz approximation)
float3 ACESFilmic(float3 x) {
    const float a = 2.51;
    const float b = 0.03;
    const float c = 2.43;
    const float d = 0.59;
    const float e = 0.14;
    return saturate((x * (a * x + b)) / (x * (c * x + d) + e));
}

cbuffer CompositeCB : register(b0) {
    float exposure;
    float bloomIntensity;
    float vignette;
    float chromaticAberration;
    float filmGrain;
    float time;
    float2 _pad;
};

float4 PSComposite(VSOut i) : SV_Target {
    // Chromatic aberration (опционально)
    float2 offset = (i.uv - 0.5) * chromaticAberration * 0.01;
    float3 scene;
    scene.r = g_scene.Sample(g_samp, i.uv + offset).r;
    scene.g = g_scene.Sample(g_samp, i.uv).g;
    scene.b = g_scene.Sample(g_samp, i.uv - offset).b;

    // Bloom
    float3 bloom = g_bloom.Sample(g_samp, i.uv).rgb * bloomIntensity;
    float3 color = scene + bloom;

    // Exposure
    color *= exposure;

    // Tone mapping
    color = ACESFilmic(color);

    // Vignette
    float2 d = i.uv - 0.5;
    float vig = 1.0 - dot(d, d) * vignette;
    color *= vig;

    // Film grain
    float grain = frac(sin(dot(i.uv + time * 0.1, float2(12.9898, 78.233))) * 43758.5453);
    color += (grain - 0.5) * filmGrain * 0.1;

    return float4(color, 1);
}

Постпроцессный AA для сцен без MSAA. Дешёвый, но мылит текст. Для UI — лучше MSAA (Урок 9).

float4 PSFXAA(VSOut i) : SV_Target {
    float2 texel = 1.0 / float2(W, H);
    float3 rgbM = g_scene.Sample(g_samp, i.uv).rgb;

    float3 rgbNW = g_scene.Sample(g_samp, i.uv + texel * float2(-1, -1)).rgb;
    float3 rgbNE = g_scene.Sample(g_samp, i.uv + texel * float2( 1, -1)).rgb;
    float3 rgbSW = g_scene.Sample(g_samp, i.uv + texel * float2(-1,  1)).rgb;
    float3 rgbSE = g_scene.Sample(g_samp, i.uv + texel * float2( 1,  1)).rgb;

    float lumaNW = dot(rgbNW, float3(0.299, 0.587, 0.114));
    float lumaNE = dot(rgbNE, float3(0.299, 0.587, 0.114));
    float lumaSW = dot(rgbSW, float3(0.299, 0.587, 0.114));
    float lumaSE = dot(rgbSE, float3(0.299, 0.587, 0.114));

    float lumaMin = min(lumaM, min(min(lumaNW, lumaNE), min(lumaSW, lumaSE)));
    float lumaMax = max(lumaM, max(max(lumaNW, lumaNE), max(lumaSW, lumaSE)));

    if (abs(lumaMax - lumaMin) < 0.05) return float4(rgbM, 1);   // нет контраста — не трогаем

    // ... FXAA blending ...
    return float4(rgbM, 1);
}

Урок 17. Сборка во фреймворк MiniD2D

Финальная сборка всего в API, совместимый с ID2D1RenderTarget. Application, Widget hierarchy, Scene, retained mode.

17.1. Что такое MiniD2D

Это фреймворк, а не библиотека. Он собирает все уроки в единый связный API, который можно использовать как альтернативу Direct2D:

  • Application — окно, RenderThread, GameClock, scene loop.
  • Widget hierarchy — Measure/Draw/OnInput (как WPF/Avalonia).
  • Scene — дерево виджетов + input routing + focus.
  • Retained mode — кэш DrawList между кадрами (для статических частей).
  • D2D-compatible API — всё, что было в ID2D1RenderTarget, есть и здесь.

bool Application::Initialize(HINSTANCE hInst, const wchar_t* title,
                             UINT width, UINT height)
{
    // DPI awareness
    SetProcessDpiAwarenessContext(DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2);
    CoInitializeEx(nullptr, COINIT_APARTMENTTHREADED | COINIT_DISABLE_OLE1DDE);

    // Register class
    WNDCLASSEXW wc{};
    wc.cbSize = sizeof(wc);
    wc.style = CS_HREDRAW | CS_VREDRAW;
    wc.lpfnWndProc = WndProcStatic;
    wc.hInstance = hInst;
    wc.hCursor = LoadCursorW(nullptr, IDC_ARROW);
    wc.hbrBackground = (HBRUSH)GetStockObject(BLACK_BRUSH);
    wc.lpszClassName = L"MiniD2DWindow";
    RegisterClassExW(&wc);

    RECT r{ 0, 0, (LONG)width, (LONG)height };
    AdjustWindowRectEx(&r, WS_OVERLAPPEDWINDOW, FALSE, 0);

    m_hwnd = CreateWindowExW(0, wc.lpszClassName, title,
        WS_OVERLAPPEDWINDOW, CW_USEDEFAULT, CW_USEDEFAULT,
        r.right - r.left, r.bottom - r.top,
        nullptr, nullptr, hInst, this);
    if (!m_hwnd) return false;

    m_width = width;
    m_height = height;
    m_dpiScale = GetWindowDpiScale(m_hwnd);

    // Render thread
    if (!m_renderThread.Init(m_hwnd, m_width, m_height, m_dpiScale))
        return false;

    ShowWindow(m_hwnd, SW_SHOW);
    m_clock.Init();
    OnStart();
    return true;
}

int Application::Run() {
    MSG msg{};
    while (m_running) {
        while (PeekMessageW(&msg, nullptr, 0, 0, PM_REMOVE)) {
            if (msg.message == WM_QUIT) { m_running = false; break; }
            TranslateMessage(&msg);
            DispatchMessageW(&msg);
        }
        if (!m_running) break;

        if (m_renderThread.IsDeviceLost()) {
            m_renderThread.RequestDeviceRecovery();
            Sleep(100);
            continue;
        }

        m_clock.Tick();
        OnUpdate(m_clock.frameTime);

        DrawList list;
        BuildFrame(list);
        m_renderThread.Submit(std::move(list));
    }

    OnShutdown();
    m_renderThread.Shutdown();
    CoUninitialize();
    return 0;
}

class Button : public Widget {
public:
    Button(std::wstring text, std::function<void()> onClick)
        : m_text(std::move(text)), m_onClick(std::move(onClick)) {}

    Size Measure(const FontData& font, const Size&) override {
        auto m = font.Measure(m_text.c_str());
        m_measuredSize = { m.width + 40, font.LineHeight() + 20 };
        return m_measuredSize;
    }

    void Draw(DrawList& list, const FontData& font) override {
        Color bg = m_hover ? Color{0.4f, 0.6f, 1.0f, 1} : Color{0.3f, 0.5f, 0.9f, 1};
        list.FillRoundedRect(m_x, m_y, m_measuredSize.w, m_measuredSize.h, 8, bg);
        list.DrawText(m_fontId, m_text,
                      m_x + 20, m_y + 10 + font.Ascent(),
                      {1, 1, 1, 1});
    }

    bool OnInput(const InputEvent& evt) override {
        if (evt.type == InputEvent::MouseMove) {
            m_hover = Rect{m_x, m_y, m_measuredSize.w, m_measuredSize.h}
                        .Contains(evt.x, evt.y);
        }
        if (evt.type == InputEvent::MouseDown &&
            Rect{m_x, m_y, m_measuredSize.w, m_measuredSize.h}
                .Contains(evt.x, evt.y)) {
            if (m_onClick) m_onClick();
            return true;
        }
        return false;
    }

    void SetFontId(uint32_t id) { m_fontId = id; }

private:
    std::wstring m_text;
    std::function<void()> m_onClick;
    uint32_t m_fontId = 0;
    bool m_hover = false;
};

class Panel : public Widget {
public:
    Panel(Color bg = {0.15f, 0.15f, 0.2f, 1}) : m_bg(bg) {}

    void Add(std::unique_ptr<Widget> w) { m_children.push_back(std::move(w)); }

    Size Measure(const FontData& font, const Size& avail) override {
        Size total{ 0, 0 };
        for (auto& c : m_children) {
            auto s = c->Measure(font, avail);
            total.w = max(total.w, c->X() + s.w);
            total.h = max(total.h, c->Y() + s.h);
        }
        m_measuredSize = total;
        return total;
    }

    void Draw(DrawList& list, const FontData& font) override {
        if (m_bg.a > 0) {
            list.FillRect(m_x, m_y, m_measuredSize.w, m_measuredSize.h, m_bg);
        }
        for (auto& c : m_children) {
            // Сдвиг детей относительно панели
            list.PushTransform(XMMatrixTranslation(m_x, m_y, 0));
            c->Draw(list, font);
            list.PopTransform();
        }
    }

    bool OnInput(const InputEvent& evt) override {
        // Back-to-front (сверху вниз)
        for (auto it = m_children.rbegin(); it != m_children.rend(); ++it) {
            InputEvent local = evt;
            local.x -= m_x;
            local.y -= m_y;
            if ((*it)->OnInput(local)) return true;
        }
        return false;
    }

private:
    std::vector<std::unique_ptr<Widget>> m_children;
    Color m_bg;
};

17.7. Retained mode — кэш DrawList

Для статических UI (без анимации) DrawList не меняется. Можно кэшировать:

class CachedLayer {
public:
    void Begin() {
        if (m_dirty) m_list.Reset();
    }
    void End() {
        if (m_dirty) m_dirty = false;
    }

    DrawList& List() { return m_list; }
    void Invalidate() { m_dirty = true; }

private:
    DrawList m_list;
    bool m_dirty = true;
};

// В BuildFrame:
if (sceneDirty) {
    cachedLayer.Begin();
    m_scene.Draw(cachedLayer.List(), font);
    cachedLayer.End();
    sceneDirty = false;
}

// Копируем кэшированный DrawList в финальный
for (auto& cmd : cachedLayer.List().Commands()) {
    finalList.Append(cmd);   // или std::vector copy
}
Реальный выигрыш: layout + build DrawList для 200 виджетов = ~1 ms на main thread. С кэшем — 0.05 ms (только copy). При 60 FPS это 6% бюджета. Для сложных UI — критично.

E.3. Практические советы

  1. Debug layer — всегда включён. Output Window чистый = хороший день.
  2. IDXGIDebug в конце — 0 объектов. Иначе — утечка.
  3. RenderDoc для визуальной отладки. F12 в любой момент — frame capture.
  4. Профилируй до оптимизации. PIX/Concurrency Visualizer покажут, где реально bottleneck.
  5. Не оптимизируй батчинг руками. Группируй по атласу в UI-дереве — всё.
  6. Тестируй на слабом железе. Intel UHD — отличный стресс-тест (низкая VRAM, слабый PS).
  7. DPI 150% и 200% — обязательно. Мыло заметно, пользователь не простит.
  8. Device lost recovery — не опция. Обновление драйвера в фоне — норма.
  9. Текст — самое сложное. DWrite — стандарт, не изобретай заново.
  10. Не бойся переписывать. Первая версия — для понимания, вторая — для продакшена.
